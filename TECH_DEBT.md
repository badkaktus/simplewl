# Технический долг

Список проблем, найденных при ревью проекта. Отмечайте пункты по мере исправления.

## 🔴 Безопасность

- [x] **IDOR при смене приватности вишлиста.** `ChangeWishlistVisibilityRequest` проверяет права
  на вишлист текущего пользователя, а `WishlistController::changeVisibility` переключает вишлист
  пользователя из URL. Любой залогиненный может сделать чужой приватный список публичным.
- [x] **Захват аккаунта через Telegram.** `Services/Auth/Telegram` ищет существующего пользователя
  по `name`, который произвольный и неуникальный.
- [x] **Захват аккаунта через GitHub без публичного email.** `whereEmail(null)` превращается в
  `WHERE email IS NULL` и находит первого пользователя без email (например, из Telegram).
- [x] **SSRF через `image_url`.** `WishService::saveImageToLocal` скачивает любой URL (включая
  `localhost`, приватные сети, metadata-эндпоинты) и кладёт ответ в публичный storage. Нет таймаута,
  лимита размера, проверки содержимого; SVG сохраняется как есть (stored XSS).
- [x] **`users.name` не уникален**, хотя используется как публичный URL `/wishlist/{name}`.
  Регистрация и профиль позволяют занять чужое имя.
- [x] **`GET /wish/{wish}/edit` без проверки прав** — любой залогиненный видит форму чужого желания,
  в том числе из приватного списка.
- [x] **`/generate-description` без rate limit** — неограниченный расход бюджета OpenAI.

## 🟠 Логика

- [x] **Slug желания уникален только в вишлисте, а route binding ищет глобально.** При совпадении
  slug у двух пользователей открывается чужое желание, а владелец получает 403 при
  редактировании/удалении своего. Нужен scoped binding.
- [x] **Очистка Image URL при редактировании → TypeError / 500** (`saveImageToLocal(null)`).
- [ ] **Старые локальные картинки не удаляются** при замене картинки и удалении желания.
- [ ] **Несуществующий пользователь или вишлист → 500** вместо 404 (`WishlistController::index`).
- [x] **`Http::head()` в Blade** (`image-with-check`) — синхронный запрос на каждую карточку без
  таймаута.
- [ ] **«Choose a currency» отправляет `currency=0`**, в БД пишется `"0"`.
- [ ] **OAuth: событие `Registered` срабатывает для существующих пользователей**, а в
  `user_attributes` вставляется новая строка вместо обновления (у таблицы нет PK).
- [ ] **Генерация описания не обрабатывает ошибки OpenAI** (500, фронт молчит); URL товара в промпт
  не передаётся, язык жёстко английский.
- [ ] **Имя пользователя со `/` делает публичный вишлист недоступным** — нужна валидация символов.

## 🟡 CI и инфраструктура

- [ ] **`vendor/bin/pint` в CI без `--test`** — форматирование никогда не роняет сборку.
- [ ] **Два lock-файла** (`yarn.lock` и `package-lock.json`): CI проверяет npm, Docker собирает yarn.
- [ ] **`debug` в `docker/frankenphp/Caddyfile`** в продакшене.
- [ ] **`wishes.tar.gz` в корне** не исключён в `.gitignore` / `.dockerignore`.
- [ ] **`larastan` в `require`** вместо `require-dev`.
- [ ] **Неиспользуемые зависимости:** `doctrine/dbal`, `socialiteproviders/facebook`, `laravel/sanctum`,
  `@tailwindcss/aspect-ratio`.
- [ ] **`currency:sync` не запланирован** в scheduler.
